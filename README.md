# MultiShop Mikroservis Projesi - .NET Core 6.0

# Genel Bakış
 Bu proje, esneklik ve ölçeklenebilirlik sağlamak için modern, mikroservis tabanlı bir mimariyle geliştirilmiştir. Docker desteği, güvenli ve taşınabilir bir dağıtım ortamı sunmak için sorunsuz bir şekilde entegre edilmiştir. Sistem, MSSQL, MongoDB, Redis ve PostgreSQL dahil olmak üzere çeşitli SQL ve NoSQL veritabanlarıyla sorunsuz bir şekilde çalışacak şekilde optimize edilmiştir.

## Proje Özellikleri:

#### Mikroservis Mimarisi

🏗️ Mikroservis Mimarisi: Esnek, ölçeklenebilir ve SOLID uyumlu bir tasarım sağlamak için Katmanlı ve Soğan Mimarisi uygulanmıştır.

#### Tasarım Desenleri

🧩 Tasarım Desenleri: Modülerlik ve sürdürülebilirliği artırmak için Repository, CQRS ve Mediator desenleri kullanılmıştır.

#### Güvenlik

🔐 Güvenlik: Güçlü kullanıcı kimlik doğrulama ve yetkilendirme için Identity Server ve JWT kullanılmıştır.

#### Veritabanı Desteği

💾 Veritabanı Desteği: MSSQL, MongoDB, Redis ve PostgreSQL için verimli veri yönetimi sağlanmıştır.

#### API Gateway

🌐 API Gateway: API yönlendirme için Ocelot Gateway kullanılmış ve Swagger tarafından üretilen dökümantasyon ile desteklenmiştir.

#### Gerçek Zamanlı İletişim

📲 Gerçek Zamanlı İletişim: Sayfa yenilemelerine gerek kalmadan canlı güncellemeler ve bildirimler için SignalR kullanılmıştır.

#### Test ve Doğrulama

✅ Test ve Doğrulama: API fonksiyonelliği, Postman ile titizlikle test edilip doğrulanmıştır.

#### Kullanılan Teknolojiler:

Backend:

🖥️ Backend: ASP.NET Core 6.0 Web API

#### Veritabanları:

🗄️ Veritabanları: MSSQL, MongoDB, Redis, PostgreSQL

#### Containerization:

🐳 Containerization: Docker ile dağıtım ve yönetim kolaylaştırılmıştır.

#### Veritabanı Araçları:

🛠️ Veritabanı Araçları: DBeaver, Dapper ile verimli veri erişimi ve yönetimi

#### API Testi:

🔍 API Testi: Postman ve Swagger ile uç nokta doğrulama ve dökümantasyon

#### Mesajlaşma Kuyruğu:

📩 Mesajlaşma Kuyruğu: RabbitMQ ile güvenilir mesaj yönetimi

#### Bulut Depolama:

☁️ Bulut Depolama: Google Cloud Storage ile ölçeklenebilir veri depolama çözümleri

#### Mimari Desenler:

🧭 Mimari Desenler: Soğan Mimarisi, CQRS, Mediator ve Repository Tasarım Deseni ile sürdürülebilir ve modüler tasarım

#### Güvenlik:

🔒 Güvenlik: Identity Server ve JWT ile kimlik doğrulama ve yetkilendirme

#### API Gateway:

🛣️ API Gateway: Ocelot Gateway ile API yönlendirme ve birleşim

#### Gerçek Zamanlı Özellikler:

📡 Gerçek Zamanlı Özellikler: SignalR ile canlı bildirimler ve güncellemeler

#### Frontend Teknolojileri:

🎨 Frontend Teknolojileri: HTML, CSS, JavaScript ve Bootstrap

Bu ikonlar, projeyi görsel olarak daha ilgi çekici hale getirecek ve kullanıcıların proje özelliklerini daha hızlı anlamasına yardımcı olacaktır.
